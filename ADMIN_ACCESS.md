# Доступ к админ панели

## Учетные данные администратора

Для доступа к админ панели используйте следующие данные:

**Администратор:**
- Email: `admin@runcode.dev`
- Password: `admin123`
- Role: `ADMIN`

**Модератор:**
- Email: `moderator@runcode.dev`
- Password: `moderator123`
- Role: `MODERATOR`

## Как войти в админ панель

1. Перейдите на главную страницу приложения
2. Нажмите кнопку "Войти" в правом верхнем углу
3. Введите email и пароль администратора
4. После входа в навигационном меню появится пункт "Админ"
5. Нажмите на "Админ" для перехода в админ панель

## Права доступа

- **ADMIN** - полный доступ ко всем функциям админ панели
- **MODERATOR** - доступ к управлению заданиями и пользователями (ограниченный)
- **USER** - нет доступа к админ панели

## Функции админ панели

1. **Dashboard** - общая статистика и обзор
2. **Управление заданиями** - создание, редактирование, удаление заданий
3. **Управление языками** - добавление и настройка языков программирования
4. **Управление пользователями** - просмотр и модерация пользователей
5. **Системные настройки** - конфигурация приложения

## Безопасность

- Middleware автоматически проверяет права доступа
- Неавторизованные пользователи перенаправляются на главную страницу
- API endpoints также защищены проверкой ролей

## Создание новых админов

Для создания новых администраторов:
1. Зарегистрируйте пользователя обычным способом
2. В базе данных измените поле `role` с `USER` на `ADMIN` или `MODERATOR`
3. Пользователь получит доступ к админ панели при следующем входе
