# Rating Feature Components

Компоненты для страницы рейтинга пользователей платформы RunCode.

## Компоненты

### RatingHeader
Заголовок страницы рейтинга с анимацией появления.

**Функции:**
- Отображает заголовок и описание страницы
- Анимированное появление с GSAP

### RatingSearch
Компонент поиска пользователей с анимированными элементами.

**Пропсы:**
- `searchQuery: string` - текущий поисковый запрос
- `onSearchChange: (query: string) => void` - обработчик изменения поиска

**Функции:**
- Поиск по имени пользователя или уровню
- Анимированная иконка поиска
- Кнопка очистки с анимацией появления/исчезновения

### BasicFilters
Основные фильтры для выбора периода времени и переключения расширенных фильтров.

**Пропсы:**
- `selectedPeriod: 'week' | 'month' | 'all'` - выбранный период
- `onPeriodChange: (period) => void` - обработчик изменения периода
- `showAdvancedFilters: boolean` - состояние показа расширенных фильтров
- `onToggleAdvancedFilters: () => void` - переключатель расширенных фильтров

### RatingStats
Отображает общую статистику платформы в виде карточек.

**Пропсы:**
- `users: User[]` - массив пользователей для расчета статистики

**Функции:**
- Показывает общее количество участников
- Отображает количество решенных заданий
- Показывает общий рейтинг всех пользователей
- Отображает лучшую серию дней подряд
- Показывает количество наград
- Отображает средний рейтинг
- Показывает активных сегодня пользователей
- Показывает новых пользователей за месяц

### TopThreeUsers
Специальный компонент для отображения топ-3 пользователей в стиле подиума.

**Пропсы:**
- `users: User[]` - массив пользователей (берутся первые 3)
- `onUserClick: (user: User) => void` - обработчик клика по пользователю

**Особенности:**
- Отображает пользователей в порядке 2-1-3 (как на подиуме)
- Разные размеры карточек для каждого места
- Анимированное появление с задержками
- Специальные эффекты для первого места
- Уникальные иконки и цвета для каждого ранга

### RemainingUsersList
Список остальных участников (начиная с 4-го места) с ScrollTrigger анимациями.

**Пропсы:**
- `users: User[]` - массив пользователей (отображаются начиная с 4-го)
- `onUserClick: (user: User) => void` - обработчик клика по пользователю

**Особенности:**
- Использует GSAP ScrollTrigger для анимаций при скролле
- Анимация появления при входе в viewport
- Анимация исчезновения при выходе из viewport
- Отдельная анимация для заголовка секции
- Автоматическая очистка ScrollTrigger при размонтировании

### RatingFilters
Расширенные фильтры для сортировки и фильтрации рейтинга.

**Пропсы:**
- `selectedPeriod: 'week' | 'month' | 'all'` - выбранный период
- `onPeriodChange: (period) => void` - обработчик изменения периода
- `sortBy: 'points' | 'tasks' | 'streak' | 'joined'` - поле сортировки
- `onSortChange: (sort) => void` - обработчик изменения сортировки
- `sortOrder: 'asc' | 'desc'` - порядок сортировки
- `onSortOrderChange: (order) => void` - обработчик изменения порядка
- `levelFilter: string` - фильтр по уровню
- `onLevelFilterChange: (level) => void` - обработчик изменения уровня

**Функции:**
- Фильтрация по периоду времени
- Сортировка по различным критериям
- Фильтрация по уровню пользователя
- Изменение порядка сортировки

### UserProfileModal
Модальное окно с детальной информацией о пользователе.

**Пропсы:**
- `user: User | null` - данные пользователя
- `isOpen: boolean` - состояние открытия модального окна
- `onClose: () => void` - обработчик закрытия

**Функции:**
- Показывает полную информацию о пользователе
- Отображает все достижения пользователя
- Показывает статистику и даты
- Анимированное появление и исчезновение
- Закрытие по Escape или клику вне модального окна

## Анимации и ScrollTrigger

### GSAP ScrollTrigger
Компонент `RemainingUsersList` использует GSAP ScrollTrigger для создания анимаций при скролле:

- **Анимация появления**: Элементы появляются при входе в viewport (85% от верха экрана)
- **Анимация исчезновения**: Элементы исчезают при выходе из viewport (обратный скролл)
- **Stagger эффект**: Карточки пользователей появляются с небольшой задержкой друг за другом
- **Автоматическая очистка**: ScrollTrigger триггеры автоматически удаляются при размонтировании компонента

### Оптимизация анимаций
Все компоненты используют правильные зависимости в `useGSAP`:
- Анимации запускаются только при изменении соответствующих данных
- Предотвращается повторное выполнение анимаций при каждом рендере
- Используется `{ dependencies: [...] }` для контроля перезапуска анимаций

## Типы данных

### User
```typescript
interface User {
    id: number;
    username: string;
    avatar?: string;
    totalPoints: number;
    solvedTasks: number;
    rank: number;
    level: string;
    streak: number;
    joinedAt: Date;
    lastActive: Date;
    badges: Badge[];
}
```

### Badge
```typescript
interface Badge {
    id: number;
    name: string;
    icon: string;
    description: string;
    rarity: 'common' | 'rare' | 'epic' | 'legendary';
}
```
